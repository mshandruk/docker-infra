# docker-infra

A collection of Docker Compose stacks for fast and simple deployment of infrastructure services.

## Prerequisites

Install docker

1. Clone the configuration repository:

```bash
git clone https://github.com/mshandruk/ansible-infra.git
```

2. [Docker installation guide](https://github.com/mshandruk/ansible-infra/blob/master/roles/docker/README.md)
